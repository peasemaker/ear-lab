# Ear Lab

Веб-приложение для тренировки музыкального слуха: распознавание ступеней мажорной гаммы с выбором эмбиентного тембра или акустического пианино. React, TypeScript, Vite, Tone.js, Tonal.js и обычный CSS. Backend и регистрация не нужны.

## Запуск

Нужен Node.js 22.12+ или 24 LTS и npm. Проект проверен на Node.js 24.

```bash
npm install
npm run dev
```

Откройте адрес из терминала, обычно **http://localhost:5173**. Если порт занят, Vite предложит следующий свободный порт.

Для просмотра с телефона в той же Wi-Fi сети:

```bash
npm run dev -- --host 0.0.0.0
```

Откройте на телефоне адрес `Network`, который напечатает Vite. Разрешите локальную сеть, если это потребуется системе. На телефоне может потребоваться отключить беззвучный режим.

## Как тренироваться

1. Выберите одну из 12 тональностей, доступные ступени, октавы и «Звук ступени»: «Эмбиент» или «Пианино». Хотя бы одна ступень и одна октава должны оставаться включёнными. По умолчанию активны все три регистра: нижний, основной и верхний.
2. Нажмите «Слушать». Включится тихий непрерывный тонический фон, а поверх него прозвучит случайная доступная ступень той же мажорной гаммы. Короткое нажатие воспроизводит ступень одну секунду с плавным затуханием. Если зажать кнопку, ступень звучит до отпускания; удержание распознаётся через 350 мс.
3. После прослушивания эта же кнопка станет «Повторить»: она воспроизводит прежнюю ступень поверх фона. Удержание работает во всех состояниях основной кнопки. Работают мышь, сенсорный экран и клавиши Space/Enter на выбранной кнопке.
4. Выберите ответ 1–7 и нажмите «Проверить». Приложение покажет правильную ступень и название ноты.
5. После проверки основная кнопка станет «Следующее задание». Нажмите её для нового вопроса.

Фон продолжает звучать во время выбора ответа, проверки и перехода к следующему заданию. Кнопка «Выключить тонический фон» останавливает только фон; следующее прослушивание включает его снова. Отпускание кнопки вне её границ, отмена касания или переключение вкладки завершают удерживаемую ступень. Смена тональности плавно перестраивает активный фон на новую тонику, а смена набора ступеней сохраняет его. Обе настройки отменяют текущую ступень и сбрасывают вопрос; выключенный фон при этом не включается. Счётчик верных ответов хранится только до перезагрузки страницы. Задания выбираются равновероятно; одна ступень может выпасть несколько раз подряд.

Звук начинается только после нажатия: это требование браузеров к Web Audio. Эмбиент звучит мягким синтезированным pad с плавной атакой. Верхние гармоники ступени ослаблены low-pass-фильтром, срез которого подстраивается под ноту. Пианино использует 16 записанных сэмплов Salamander Grand Piano (около 1 МБ), загружаемых с самого сайта при первом выборе. Во время загрузки кнопка прослушивания заблокирована; загруженный инструмент повторно используется до перезагрузки страницы. Пианино звучит без фильтра и реверберации, а при удержании естественно затухает. При ошибке загрузки можно повторить прослушивание или выбрать эмбиент.

Для тонического фона используется общий для двух тембров тёплый синтезатор с мягкими обертонами, фильтром и лёгкой реверберацией. Высота звука остаётся точной, без расстройки и хоруса. Громкость инструментов подобрана отдельно, чтобы ступень оставалась различимой поверх фона. Смена тембра сбрасывает вопрос и сохраняет счёт и тонический фон. При первом воспроизведении приложение дожидается подготовки реверберации и выбранного инструмента.

Правильная ступень и нота остаются скрытыми до проверки. Доступны регистры относительно основной гаммы: −1 октава, без сдвига и +1 октава. Все включённые пары «ступень × регистр» выбираются равновероятно; при всех семи ступенях и трёх октавах это 21 вариант. В До мажоре полный диапазон `C3`–`B5`, в Си мажоре — `B3`–`A#6`. Ответ в любой октаве остаётся числом 1–7. В настройках показывается диапазон выбранных ступеней; повтор сохраняет исходную ноту и октаву.

Фоновая тоника сохраняет прежний басовый регистр `F#2`–`F3`: например, `C3` для До мажора и `B2` для Си мажора. Эти две тоники находятся рядом по высоте, с разницей в полтона. Переключение регистров ступеней не меняет высоту фона; нижняя I ступень может звучать с ним в унисон. Ноты указаны в научной нотации (`C4` — среднее до).

Сэмплы пианино: Salamander Grand Piano, Alexander Holm, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Источник и атрибуция: [public/audio/piano/README.md](./public/audio/piano/README.md).

## Проверки и сборка

```bash
npm test             # музыкальные интервалы, жизненный цикл задания, отмена звука
npm run build       # TypeScript и production-сборка в dist/
npm run preview     # локальный просмотр production-сборки
```

Тесты проверяют интервалы всех семи ступеней во всех тональностях и регистрах, альтерации и переход через октаву, выбор из доступных ступеней и регистров, отображаемый диапазон, защиту от повторного зачёта и отмену воспроизведения. Реальное качество звука и поведение конкретного мобильного браузера проверяются вручную.

## Публикация на GitHub Pages

Репозиторий: [peasemaker/ear-lab](https://github.com/peasemaker/ear-lab).
Ожидаемый адрес после успешной публикации: **https://peasemaker.github.io/ear-lab/**.

1. Откройте [Settings → Pages](https://github.com/peasemaker/ear-lab/settings/pages).
2. В `Build and deployment → Source` выберите **GitHub Actions**.
3. Закоммитьте `.github/workflows/deploy.yml` и обновлённый `README.md`, затем отправьте изменения в ветку `main`.
4. Во вкладке [Actions](https://github.com/peasemaker/ear-lab/actions) дождитесь успешного завершения **Deploy Ear Lab to GitHub Pages**. Ссылка на сайт появится в результате deployment и в настройках Pages.

Workflow автоматически запускает `npm ci`, тесты, сборку и публикацию `dist` при каждом push в `main`. Также его можно запустить вручную через `Actions → Deploy Ear Lab to GitHub Pages → Run workflow`. Личные токены и ветка `gh-pages` не нужны; используются стандартные разрешения `GITHUB_TOKEN`. Папки `node_modules` и `dist` в репозиторий не добавляются.

Базовый путь сборки берётся из метаданных GitHub Pages через `actions/configure-pages`: `/ear-lab/` для стандартного адреса, `/` для собственного домена. Локальная разработка сохраняет путь `/`, менять `vite.config.ts` не требуется.

Проверить сборку под стандартный адрес локально можно так:

```bash
npm run build -- --base=/ear-lab/
npm run preview -- --base=/ear-lab/
```

Откройте `http://localhost:4173/ear-lab/` или адрес с портом из терминала.

Для собственного домена укажите его в `Settings → Pages → Custom domain`, настройте DNS у регистратора по [инструкции GitHub](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site) и включите `Enforce HTTPS`, когда опция станет доступна. После подключения домена повторно запустите workflow, чтобы пересобрать сайт с новым базовым путём. При публикации через этот workflow файл `CNAME` не требуется.

## Архитектура

```text
src/
  music/
    majorScale.ts        # гаммы Tonal.js, ступени, генерация вопроса, имена нот
    session.ts           # чистый reducer: ответ, проверка, счёт, состояния
    *.test.ts            # тесты музыкальной логики и состояний
  audio/
    piano.ts             # Tone.js, постоянный фон, ступень, отмена, очистка
    piano.test.ts        # тесты фона, сэмплера, загрузки и отмены воспроизведения
    sounds.ts            # доступные тембры и их подписи
  hooks/
    useExercise.ts       # связывает настройки, reducer и аудиодвижок
  components/
    SettingsPanel.tsx    # тональность и доступные ступени
    ListeningPanel.tsx   # прослушивание и повтор
    ListenButton.tsx     # короткое нажатие и удержание мышью, касанием, клавиатурой
    AnswerPanel.tsx      # выбор ответа и обратная связь
    Icon.tsx             # общие SVG-иконки
  App.tsx                # композиция страницы
  App.css                # интерфейс и адаптивная сетка
  index.css              # базовые стили и типографика
```

Музыкальная логика не зависит от React или Web Audio; аудиодвижок не знает об интерфейсе и проверке ответа. React-компоненты получают данные и обработчики через props. Соглашения для дальнейшей разработки — в [AGENTS.md](./AGENTS.md).

Интерфейс адаптируется к ширине от 320 px, поддерживает клавиатурную навигацию, объявления результата для скринридеров и `prefers-reduced-motion`. Шрифт Manrope загружается из Google Fonts; при отсутствии сети используются системные шрифты. Аудио работает локально.
